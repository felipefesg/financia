# Segurança

## Reporte vulnerabilidades

Para reportar uma vulnerabilidade de segurança no FinancIA, abra um **GitHub Security Advisory deste repositório**.

Por favor, inclua:
- Uma descrição do problema
- Passos para reproduzir
- Impacto esperado
- Quaisquer detalhes de ambiente relevantes

Não envie e-mails com assuntos não relacionados a segurança.
